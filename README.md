# 《戴森球计划》蓝图预览 & 发电量计算 & 彩绘生成

纯前端的《戴森球计划》 `戴森球蓝图` 预览工具：可查看 3D 戴森球结构、壳层/云轨道明细与发电量估算。

## 功能
### 戴森球预览
- **3D 预览**：戴森壳、戴森云的实时 3D 渲染，模拟戴森壳自转，恒星颜色随恒星光度变化
- **发电量计算**：计算戴森壳的发电量，节点/框架/壳面可单独计算，单层壳支持自定义半径
- **信息面板**：蓝图信息、建造总量、壳层与云轨道的逐层明细
- **蓝图功能**：可以根据单层壳生成多层壳，从蓝图中提取云或壳
### 工厂蓝图预览
- **3D 预览**：在星球上查看蓝图布局，可选择放置纬度，建筑的模型使用建造碰撞箱（传送带和分拣器除外）
- **蓝图信息**：显示与编辑缩略图、蓝图介绍与属性等富文本内容排版
- **建筑详情**：点击建筑可查看详情，可高亮一整条传送带
- **编辑蓝图**：可修改部分建筑配置，物流塔设置，切换本地物流塔与星际物流塔
### 生成彩绘
- 可根据图片生成`壳面/地基`像素画

## 开发

推荐使用 **Node.js 20** 或更高版本。

### 命令

```bash
npm install            # 安装依赖
npm run dev            # 运行开发服务器
npm run build          # 构建静态文件到 dist/
npm run preview        # 本地浏览 dist/ 构建产物
```
