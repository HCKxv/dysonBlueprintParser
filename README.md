# 戴森球蓝图预览 & 发电量计算

纯前端的《戴森球计划》 `戴森球蓝图` 预览工具：粘贴或拖入蓝图，即可查看 3D 戴森球结构、壳层/云轨道明细与发电量估算。

## 功能

- **3D 预览**：戴森壳、戴森云的实时 3D 渲染，模拟戴森壳自转，恒星颜色随恒星光度变化
- **发电量计算**：按游戏公式估算`功率(kW) = (结构点数×96 + 细胞点数×15) × 恒星光度`，节点/框架/壳面可单独计算，单层壳支持自定义半径
- **信息面板**：蓝图信息、建造总量、壳层与云轨道的逐层明细

## 使用

粘贴蓝图代码后点击解析按钮，或直接拖入蓝图文件。
