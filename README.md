# 戴森球蓝图预览 & 发电量计算

《戴森球计划》戴森球蓝图预览工具。纯前端运行，无需后端，支持离线使用。

## 功能

- **3D 预览**：戴森壳、戴森云的实时 3D 渲染，模拟戴森壳自转，恒星颜色随恒星光度变化
- **发电量计算**：计算戴森壳的发电量，节点/框架/壳面可单独计算，单层壳支持自定义半径
- **信息面板**：蓝图信息、建造总量、壳层与云轨道的逐层明细
- **提取蓝图**：可以从蓝图中提取云或壳，根据单层壳生成多层壳

## 使用

复制以 `DYBP:` 开头的蓝图代码，粘贴到输入框并点击「解析并预览」；或直接把蓝图 `.txt` 文件拖到输入框中。

在线访问地址：

> https://hckxv.github.io/dysonBlueprintParser/
